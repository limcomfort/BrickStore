# BrickStore Mobile

Мобильное приложение BrickStore на Flutter (Android). Источник данных —
Payload CMS из корня репозитория, отдельного бэкенда нет.

## Что умеет

- Вход по имени и e-mail (без пароля), как на сайте.
- Каталог с фильтром по категориям и свежим списком из CMS.
- Карточка набора: изображение, артикул, описание, цена, характеристики.
- Избранное: добавление и снятие, синхронизация с сервером.

## Запуск

```bash
cd mobile
flutter pub get
flutter run --dart-define=BRICKSTORE_API_URL=http://10.0.2.2:3000
```

`10.0.2.2` — это `localhost` машины разработчика с точки зрения
Android-эмулятора, поэтому CMS должна быть запущена локально на порту 3000.
Для реального устройства укажите IP машины в локальной сети, для продакшна —
https-адрес.

## Авторизация

Приложение не работает с httpOnly-cookie: оно отправляет заголовок
`x-client: mobile`, получает токен сессии в теле ответа и дальше передаёт его
как `Authorization: Bearer`. Токен хранится в `shared_preferences`.

Серверная часть этой схемы описана в `src/lib/customer-session.ts` в корне
репозитория.

## Структура

```
lib/
  data/     клиент REST API, модели, состояние приложения
  screens/  вход, каталог, карточка товара, избранное
  ui/       тема, карточка товара, загрузка изображений
```

Медиа в демо-данных хранятся в SVG, поэтому изображения рендерятся через
`flutter_svg` (`lib/ui/remote_image.dart`), а не через `Image.network`.

## Проверка

```bash
flutter analyze
flutter test
flutter build apk --debug
```

Cleartext-трафик разрешён только для `10.0.2.2`, `localhost` и `127.0.0.1`
(`android/app/src/main/res/xml/network_security_config.xml`).
